# فالِ فان (fal-e-fun)

یک برنامه وب فارسی و راست‌به‌چپ با Streamlit برای چند تجربه نمادین و سرگرم‌کننده: برج غربی، زودیاک چینی، عددشناسی، پیام روز، هماهنگی دو برج و وضعیت تقریبی آسمان.

> **هشدار مهم:** این برنامه فقط برای سرگرمی و خودشناسی سبک است. نتایج قطعی، علمی یا پیش‌گویانه نیستند و نباید برای تصمیم‌های پزشکی، حقوقی، مالی یا دیگر تصمیم‌های مهم استفاده شوند.

## اجرا

پیش‌نیاز: Python 3.9 یا جدیدتر.

### Linux / macOS

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

پس از اجرا، نشانی محلی نمایش‌داده‌شده توسط Streamlit را در مرورگر باز کنید.

## داده‌های اینترنتی

اگر شهر وارد شود، برنامه برای مکان‌یابی تقریبی از Nominatim با User-Agent مشخص استفاده می‌کند و طلوع/غروب را از `sunrise-sunset.org` می‌گیرد. از `timeapi.io` نیز برای بررسی زمینه زمانی استفاده می‌شود. همه درخواست‌ها timeout دارند و در خطا، برنامه با پیام مناسب یا حالت تقریبی ادامه می‌دهد. هیچ API key یا راز دسترسی لازم نیست.

## حریم خصوصی

اطلاعات فرم در این برنامه ذخیره نمی‌شود. نام شهر، در صورت وارد شدن، برای درخواست مکان‌یابی به سرویس عمومی ارسال می‌شود. پیش از استفاده از سرویس‌های آنلاین، سیاست‌های آن‌ها را بررسی کنید.
